## Locked decisions

1. `cmd/connectorgen` declares the reviewable certification allowlist exactly once, initially
   `github` and `postgres`. It emits one definition-local
   `internal/connectors/defs/<connector>/certification-matrix.json` shard only for a requested,
   allowlisted connector. Adding a certified connector is one allowlist-line change plus its
   generated shard. The previous checked-in capability and flow aggregates are removed; no shard
   stores global baselines, counters, or ordering.
2. Do **not** reuse `certification.json`. `docs/migration/conventions.md` and
   `internal/connectors/engine/schema/certification.schema.json` reserve it for optional,
   hand-authored, harness-only metadata. Mixing generator output into it would change its schema,
   semantics, and validation contract. The generated sibling is deliberately not embedded in the
   runtime bundle.
3. The existing small `internal/connectors/certifications/status.json` remains an embedded runtime
   projection. The generator derives it from the allowlisted in-memory certification view; an
   unallowlisted connector retains the existing `COMMUNITY BUILD, UNCERTIFIED` presentation without
   claiming pass or fail. No consumer reads either retired aggregate matrix at runtime.
4. Generated source anchors use `relative/path.go:Symbol`. Fields use `Type.Field`, functions use
   the declared function identifier, and operation cases use
   `expectedOperationBlock(kind=<operation>)` because multiple operation literals can reside in one
   `case` clause. This is the narrowest stable identifier for that otherwise ambiguous construct.
5. Mechanically split `internal/app/app.go` via an Open-time transport-composition helper and an
   ETL mode-dispatch helper, preserving call order and return paths exactly. Convert the PostgreSQL
   capability override to an ordered row table with the same lone `CDC=false` result.
6. `internal/connectors/database` is absent on this `main` base; do not invent or backport its
   tests from `origin/feat/3972-postgres-parity`.
