## Threat model

| Threat | Boundary | Mitigation | Proof |
| --- | --- | --- | --- |
| One matched policy spends capacity before a second blocks | engine resolver to budget state | evaluate every policy and lease under one atomic critical section, consume only after all grant | `TestRateBudgetReserveBatchAllOrNothing` |
| A dead owner silently becomes local coordination | shared client to requester | closed `require_shared` mode maps absence/loss/incompatibility to a typed pre-send refusal | `TestRequireSharedRefusesWithoutCoordinatorBeforeSend`, crash test |
| A socket peer can broaden the protocol or overload the owner | UDS boundary | fixed version and ready/decide/finish kinds, fixed structs, count/frame limits, bounded deadlines | protocol/unit tests and malformed-frame handling |
| Socket endpoint or identity data reaches output | internal error/protocol to evidence | only opaque scopes/fingerprints/lease IDs travel; all endpoint/network errors become bounded typed errors | source review and typed-error tests |
| A client crash refunds an uncertain provider send | lease lifecycle | TTL removes only in-flight occupancy; consumptive budget state remains charged | direct decision/finish/expiry tests |
| Old reset response widens state | completion observation to state | owner clock plus existing tighten-only/reset ordering; old/ambiguous facts do not replenish | existing and new observation tests |
| A known wait cannot meet a deadline but a request starts | admission to transport | compare owner decision wait to context deadline before sleeping/retrying | `TestSharedRateBudgetDeadlineTooShortDoesNotSend` |
| Normal close leaves an owner endpoint behind | run owner to filesystem | owner owns one short 0700 directory/socket, close removes both idempotently | multiprocess residue assertion |
</threat_model>
