CI verify and focused local reproduction rejected the PostgreSQL write publication:

cmd/connectorgen TestCertificationMatrixRejectsDatabaseWriteStubs
  postgres Write stub reported declared

internal/connectors/engine TestBundleLoadPostgresDatabaseDefinitionWithProvenCDCCapability
  metadata capabilities had Write=true; expected write=false and cdc=true

Fresh shipped-binary inspection additionally reported:
  manifest.auth_modes[0].write = false
  sync_transport.destination.status = unsupported

The native Connector.Write method returns connectors.ErrUnsupportedOperation, and
DatabaseDriver documents that it is deliberately not registered. Therefore write=true
had no production dispatch and was reverted. Issue #3982 owns the destination declaration
and factory required before a future write publication can be truthful.
