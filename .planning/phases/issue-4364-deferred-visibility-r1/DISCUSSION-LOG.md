# Discussion log — issue 4364

The issue and captain authorization resolve the material design choices:

1. Deferred source cells must become discoverable before credentials,
   transport, or provider I/O, but must not become commands or executable
   declaration artifacts.
2. Source-lane semantic classification remains connector-local. The bridge
   validates the facts already recorded; it does not select by HTTP method,
   synthesize routes, or add a provider-specific exception.
3. A row outside the primary source denominator is admissible only when its
   matrix itself names a connector-owned supplemental lock and the lock proves
   the same source identity/citation. This keeps GitLab's two rendered
   binary-reference rows visible without weakening the primary 4,341-ID cohort.
4. Existing actual webhook receiver gaps remain recorded only. Their Atlas
   references are surfaced; no receiver/executor is implemented in this lane.
