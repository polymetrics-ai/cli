# pm-zendesk-support

Reads and writes allow-listed Zendesk Support resources and carries a complete blocked-by-default operation ledger for the Zendesk Support REST API v2 official OAS.

## Security

- read risk: external Zendesk Support API read across tickets, users, organizations, groups, satisfaction ratings, admin metadata, business rules, and Guide/community top-level resources
- write risk: allow-listed Zendesk Support mutations for tickets, users, organizations, groups, macros, triggers, automations, views, and ticket fields; documented destructive/delete operations remain in scope only through typed confirmation metadata or existing approved write actions
- approval: writes require reverse-ETL approval; reads require normal connector access
- Never pass secret values in chat, shell arguments, logs, docs, or JSON output.
